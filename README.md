# Study Buddy 

Study Buddy is a web application built with Django that helps students connect, share knowledge, and study together. Users can create study rooms, join discussions, and exchange ideas with others.

## Reference
```
https://github.com/Traversy-Media/StudyBud
```

## Technologies Used

- Python
- Django
- HTML & CSS
- SQLite

## Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/SAKIB0004/Study-Bud-Django-Course.git
cd Study-Bud-Django-Course
```

### 2. Create and activate a virtual environment

```bash
# Install virtualenv if you haven't already
pip install virtualenv

# Create a virtual environment
virtualenv venv

# Activate the virtual environment
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the development server

```bash
python manage.py runserver
```

The application will be available at http://127.0.0.1:8000/
